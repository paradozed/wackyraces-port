# WLogJam and WLogModel (2026-11-06)

Native: `src/port/race_objects.{h,cpp}` (`LogJam`, `JamLog`), `RaceView`, `RaceSession::solid_contacts`.

## Layout

WLogJam: vtable `0x5152fc`, init `0x4c4840`, update `0x4c4940`, restart `0x4c48d0`. Six
WLogModel children (`+0x11e`) and five GDPaths (`+0x136`). Members: `m_88` (`0x21b`, 500,
not read here), `m_90` radius (`0x21c`, 188), `m_98` gravity (`0x21d`, 3), `m_a0` drag
(`0x21e`, 1), `m_a8` bounce (`0x21f`, 0.8), `m_b0` turn (`0x220`, 0.262), `m_b8` path
(`0x221`, 0: `rand() % 5`).

WLogModel: vtable `0x515278`, update `0x4c4490`, start `0x4c3580`, step `0x4c3720`, turn
target `0x4c3100`, position `0x4c3350`, frame `0x4c2920` (`0x43c250`: spin, yaw, pi/2),
hit `0x4c43c0`, angle `0x4c4320`. Its slot `+0x34` is the base `0x411640` (returns 0): a car
bounces off, and a projectile does nothing.

## States (`+0x17e`, jump table `0x4c4604`)

| State | Update | Ends |
|---|---|---|
| 0 | hit test only (ignored at state 0) | jam: state 3 |
| 1 | step, hit | at n - 4, within `m_90` of point n - 3 with a log on that path: state 2 |
| 2 | step, hit | within 20 of point n - 3: state 0, at segment n - 3 |
| 3 | step, hit | on segment n - 2, within 50 of the last point: state 5 |
| 4 | a timer `+0x1a8` then state 0 | never entered here |
| 5 | hit test only | jam restarts it on a random path, state 1 |

**Hand-off** (`0x4c4a3f`): the struck log takes the speed; the other keeps 0.1 (`0x511624`),
leaves the air and sits on the line.

**Step:** on the ground, the gravity along the segment, x `m_a0`. In the air, y only. Past a
segment's end the next one starts in the air (`+0x19b`). Below the line in the air the point
and the speed are mirrored about it, the speed x `m_a8`; at under 2 degrees from the line, or
over 178, it lands; speed under 1 with vy within 1 of the gravity stops it.

**Primitive:** a vertical cylinder (r 100, h 500) from the centre (0, -250, 0) moved by the
frame, sensor group 0x10000. Moving logs squash (mask 0x100, type 0x200).
