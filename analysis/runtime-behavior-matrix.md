# Runtime behavior matrix

> Captures and image sheets named in this note were removed from the repository (no game content in git); the procedure described here regenerates them locally.

Runtime observations are from the Windows `wpc.exe` launched under Wine 11.20.
The best repeatable run used a disposable WoW64 prefix and an isolated copy of
the installed game files. See [`runtime-capture.md`](runtime-capture.md) for
the complete command, prefix setup, screenshots, and caveats. “Observed” means
the behavior was visible in the program or in its file/module trace; static
references alone are not counted as runtime evidence.
